## Getting started

<Steps>
  <Step title="Fork or download the repository">
    Grab the source from [GitHub](https://github.com/theinfamouscoder5/codys-shack-games) and clone it locally or directly deploy it to your static host of choice.
  </Step>
  <Step title="Configure your game library">
    Edit `config/games.json` to add, remove, or reorder games. Each entry needs a `title`, `link`, and `imgSrc`.
  </Step>
  <Step title="Deploy to a static host">
    Upload the entire project directory to any static file host. No build step is required — it's all plain HTML, CSS, and JavaScript.
  </Step>
  <Step title="Start playing">
    Open your deployed URL and navigate to the Games page to start playing immediately.
  </Step>
</Steps>
